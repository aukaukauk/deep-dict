# 新词候选的提示词

`wordlists/new-words.csv` 不是从语料里统计出来的，而是让几个大模型按领域回忆、列出近几年的新词，再合并去重得到的。下面是当时使用的提示词，原样交给各个模型。

模型返回的结果做了三步处理：

1. 去掉格式不合规的（含数字、符号）和重复的。
2. 去掉词典里已经有记录的词。
3. 逐个看过剩下的词，去掉把词组硬连写成一个词的（如 `rangeanxiety`）和看不出来源、疑似编造的。

这三步之后的词才进入 `new-words.csv`。是否收录、怎么释义，仍由生成词条的模型判断。

## 提示词

```text
你是一位熟悉英语新词的词典编辑。我在做一本英汉词典，现有词表主要来自 2021 年以前的词频数据，缺少近几年才出现或才流行起来的英语词。请你帮我尽可能多地列出这类词，作为候选词表。我只要词，不要释义。

【要什么样的词】
1. 大约 2019 年以后出现的新词，或者更早就有、但近几年才变得常见的词。
2. 英语读者在新闻、社交媒体、论坛、播客、技术文档、日常聊天里真的会反复遇到的词。
3. 各类都要：流行语和俚语、科技与行业术语、新药名和疾病名、新出现的公司、产品、平台、品牌名，以及因时事变得常见的专有名词。
4. 常见的变形可以单独列出，例如复数、过去式、-ing 形式（llms、doomscrolled、vibecoding）。

【格式上的硬性要求】
1. 只列单个词：全小写，只含 a–z 这 26 个字母，不含空格、连字符、数字、撇号。
2. 如果一个说法通常写成两个词或带连字符（如 quiet quitting、nepo baby），不要硬连写成一个词。只有连写形式本身确实通行时才列（如 brainrot、doomscroll）。
3. 只列你确信真实存在、并且见过实际用例的词。拿不准的不要列，绝对不要自己造词。
4. 不用担心和我已有的词重复，我会自己去重。宁可多列，不要漏。
5. 不要因为某个词粗俗、带贬义或有争议就略过，照常列出。

【按领域逐个回忆】
请按下面的领域一个一个过，每个领域尽量列到想不出为止，目标是每个领域至少 150 个。越新、越是最近一两年才出现的词，越要优先列。

A. 人工智能：模型与产品名、训练与推理术语、智能体与编程助手、AI 安全与治理、AI 圈的俚语
B. 软件与互联网：编程语言与框架、开发工具、云与数据、网络安全、开源社区用语
C. 加密货币与金融科技：币种与协议、交易俚语、支付与新型银行、投资圈用语
D. 社交媒体与创作者：平台及其功能、网红与直播、内容审核、平台文化
E. 网络流行语：Z 世代与 Alpha 世代俚语、梗与表情包文化、缩写、约会与人际关系用语、审美风格（各种 -core）
F. 游戏、动漫与粉丝文化：游戏类型与术语、电竞、动漫、韩流、同人与书圈
G. 影视、音乐与体育：流媒体、影视行业用语、音乐流派、新兴运动、足球等战术术语
H. 健康与医药：新药与疗法、疫情相关、心理健康与神经多样性、健身与营养、护肤与医美
I. 性别、身份与社会议题：身份与代词、社会运动、文化争论中的用语
J. 政治与国际：各国政治派别与事件、舆论战与信息操纵、战争与武器、地缘经济
K. 经济、职场与城市：通胀与经济现象、工作方式、零工与平台经济、住房与城市规划
L. 气候、能源与交通：气候现象、新能源、电动车与出行、可持续消费
M. 科学与航天：天文与航天任务、生物与基因技术、材料与物理、神经科学
N. 饮食、消费与生活方式：各国食物名、消费品牌与潮流单品、家居、宠物、旅行与户外
O. 教育与其他：教育科技、新的学习方式，以及上面没有覆盖到的任何领域

【输出格式】
每行一个词，后面用英文逗号接领域字母，例如：
chatgpt,A
shrinkflation,K
romantasy,F

除了这样的行，不要输出任何别的内容：不要标题、不要编号、不要解释、不要代码块标记。如果一次输出不完，就在上次停下的地方继续，不要重复已经列过的词。
```

## 已知的不足

- 这 15 个领域偏向关注科技的英语网民的视野，漏了不少方面：新出现的人名和地名、各地英语和外来词、商业与营销、消费电子、时尚美妆、宗教与灵性、法律与犯罪、军事、亚文化俚语、育儿、艺术设计、人文社科的新概念。体育也应当单独拆出来。
- 没有词频依据。一个词被列出来，只说明模型认为它存在，不说明它常见。
- 老词的新义抓不到。`cooked`、`aura`、`glaze` 这类词词典里早就有，按词去重时会被当成已有。
- 各模型的知识都有截止日期，更晚出现的词列不出来。
