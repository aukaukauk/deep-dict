# DeepDict V1 发布产物

这个目录是 V1（2026 年 4 月）的发布产物，V2 的数据在 `data/entries/`。

- `DeepDict.dictionary.zip`：可直接安装的 macOS 词典包。
- `included-words.csv`：V1 收录的 91,813 个词。
- `entries-merged-clean.tar.zst`：V1 全部词条 JSON（100,683 条，含被排除的记录）。
- `qa-summary.json`：V1 生成时的置信度统计。
- `SHA256SUMS`：以上文件的校验和。

安装方法见仓库根目录的 README。
